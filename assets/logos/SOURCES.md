# Institution logos

Trademarks of their respective banks and wallets, shown only to identify the
account a transaction belongs to. Downloaded 2026-09-25, trimmed and resized
to 128×128 PNG. Replace with officially supplied artwork if a bank provides
it or asks for removal. Institutions without a file here fall back to the
brand-coloured monogram in `InstitutionAvatar`.
